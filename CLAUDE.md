# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A static collection of AI product/service brand icons in SVG, WebP, and PNG format. Not a software project — no build system, dependencies, or executable code.

## Structure

- `PNG/` — ~68 icon files (primarily SVG, some WebP and PNG) for AI platforms and tools
- `icon/` — Empty directory (unused)

## Naming conventions

- Plain names: `claude.svg`, `openai.svg`, `grok.svg`
- `-color` suffix: Full-color versions (e.g., `gemini-color.svg`, `claude-color.svg`)
- `-text` suffix: Variants including the product wordmark (e.g., `claude-text.svg`)
- `(1)`, `(2)` suffixes: Duplicate/variant copies (e.g., `claude (1).svg`)
- `vecteezy_` prefix: Third-party sourced assets
